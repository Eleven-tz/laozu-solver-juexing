# 我要当老祖 · 法宝摆盘工具（觉醒版）

截图识别 + 背包摆盘优化，一体单文件，手机浏览器打开即用。

在线使用：**https://eleven-tz.github.io/laozu-solver-juexing/**

## 致谢

本工具的数据与核心算法基于 **[fradwow/laozu-solver](https://github.com/fradwow/laozu-solver)**（原作者 fradwow，[在线版](https://fradwow.github.io/laozu-solver/)），375 件法宝数据库、形状库、颜色签名与退火求解均源自原项目。觉醒功能为本分支新增。

## 功能

### 📷 截图识别
- 手动框选背包区域，自动分割 6×7 网格
- 按颜色签名识别法宝名称、品阶、元素
- 识别结果可逐格手动校正，支持"记住这个法宝的样子"学习新签名
- 一键导入优化器，一键同步锁格

### ⚔️ 摆盘优化
- 退火算法搜索最优摆法，6×7=42 格强制填满
- 相邻同系/同形态增益、长老星级加成、弟子天赋全部计入
- 结果按品阶着色（5红/4黄/3紫/2蓝/1绿），每件装备划区显示
- 战力最大化 / 自定义权重两种优化目标

### 🌟 长老法宝觉醒（本分支新增）
长老对应的五阶法宝拥有觉醒等级（背包图标右下角数字），觉醒效果**向下累积**（觉醒3包含1+2+3）：

| 觉醒等级 | 效果 |
|---|---|
| 觉醒1 | 每相邻一件指定系法宝，自身指定属性 +X%（无上限，只作用自己） |
| 觉醒2 | 自身攻/防/血基础属性 +20% |
| 觉醒3 | 两类：①背包内指定形态法宝基础属性提升（全局光环，不影响摆放）；②**相邻指定系法宝攻/防/血 +8%（影响摆法）** |

- 同一种法宝多份共用同一觉醒等级（游戏内即如此）
- 暂无数据的法宝会标红"觉醒数据缺失"，按无觉醒计算
- 在"求解设置 → 长老星级"区为每件长老红装设置觉醒等级（0~3），自动保存

## 使用

1. 手机浏览器打开上方在线地址
2. "截图识别"页：上传背包截图 → 手动框选 → 识别 → 导入优化器
3. "优化器"页：检查长老星级与觉醒等级 → 开始求解
4. 按结果图摆放即可

数据保存在浏览器 localStorage，不上传任何服务器。
